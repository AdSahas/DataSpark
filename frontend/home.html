Guide & About

Plain-language analysis
for any CSV dataset

DataSpark is an AI-powered data analysis tool that lets you ask questions about your data in plain English. No SQL, no Python, no prior data experience needed. Drop in a CSV, type a question, and get statistics, interpretations, and actionable insights in seconds.

What it is

An agent that reads your data, not just your question

Most data tools make you learn their query language. DataSpark works the other way around: you describe what you want to know, and an LLM-powered agent figures out which operations to run against your dataset to get there.

Under the hood, a LangGraph agent receives your message, selects from a set of analytical tools (descriptive stats, correlation, filtering, grouping, and more), runs them against the uploaded data, and then synthesises the results into a structured response, complete with a plain-English summary, key statistics, and an interpretive insight.

How to use it

Three steps to your first analysis

1

Upload your CSV

Click Upload CSV in the top bar and select any comma-separated file from your machine. DataSpark reads the file into memory; nothing is stored permanently. The status bar confirms when it's ready.

2

Ask a question in plain English

Type your question in the input bar at the bottom of the Dashboard and press Enter or click Analyze. You don't need to name columns precisely. The agent maps your intent to the right fields automatically.

3

Read the results

The left panel shows which analytical operations the agent ran. The right panel shows the full response: a summary, detailed statistics, an interpretation, and an insight highlighting what's most worth noticing.

Reading the output

What each section means

Summary

Plain-English answer

A one or two sentence direct answer to exactly what you asked.

Interpretation

What the numbers mean

Context around the statistics: patterns, what's normal, what stands out.

Statistics

Raw computed values

The actual numbers the agent calculated: means, counts, correlations, etc.

Insight

The most important finding

The single observation most worth acting on, surfaced from the full result.

Thinking

Agent reasoning (expandable)

The agent's internal chain of thought. Collapse it when you don't need it.

Correction

When something goes wrong

Appears if the agent couldn't complete the task, with a hint on how to rephrase.

Under the hood

How DataSpark is built

The backend is a FastAPI server that exposes two endpoints: /upload (which parses your CSV into a Pandas DataFrame held in memory) and /chat (which hands your message to the agent and returns a structured JSON response).

The agent is built with LangGraph. When you send a query, the graph routes the request through a reasoning step, selects one or more analytical tools, executes them against the in-memory DataFrame, and passes the results back to the model to produce a final structured response.

The frontend is plain HTML, CSS, and JavaScript with no framework. It sends your CSV and messages to the backend, then renders the structured response into the Operations and Analysis Results panels you see on the Dashboard.
